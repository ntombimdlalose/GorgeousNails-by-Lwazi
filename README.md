## Project Overview
GorgeousNails by Lwazi is a website created for a nail salon. The purpose of the website is to give customers information about the salon and the nail services that are offered. The website also allows customers to make an enquiry and find the salon's contact details.

## Website Goals and Objectives

The main goal of the website is to create an easy way for customers to learn about GorgeousNails by Lwazi.

The website aims to:
- Show the services offered by the nail salon.
- Provide information about the business.
- Make it easy for customers to contact the salon.
- Allow customers to make an enquiry.
- Give customers a simple and clear website to use.

## Key Features and Functionality

The website contains the following pages:

- Home – Welcomes visitors to the website and gives a short introduction.
- About Us – Provides information about GorgeousNails by Lwazi.
- Services – Shows the services offered, including manicure, pedicure, gel nails, nail art and acrylic nails.
- Enquiry – Contains a form that customers can use to make an enquiry.
- Contact – Provides the salon's phone number, email address and location.

The website also has navigation links that allow users to move between the different pages.
